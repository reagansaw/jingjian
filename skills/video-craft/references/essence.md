# 精髓：64 条成片共同的「骨架」

回答：**剪映口播模板不管哪个行业，到底共同做对了什么？** 前面的文件讲零件（版式、字体、动画、音效）；这份讲**怎么把零件排成一条片**。

## 来源与可信度（先读）
- 看了 64 条行业成片（`70口播工程` 预览，已去重）：每条每 1.2 秒抽一帧拼成接触表逐条看；另把 64 条的**第 1 秒 / 第 3 秒 / 结尾前 0.8 秒**各拼一张总览；再用对应工程文件（`template.json.bak`）的文字轨**量化**能量化的部分。
- **目测的**（接触表）：下面的「骨架 / 篇章模式」。是看出来的规律，数量写「多数 / 约一半」，**没有逐条计数**。
- **量化的**（工程文字轨，66 条）：钩子字号、结尾行动词。数字旁标了口径。
- **没看到的**：动态（只看抽帧，动画细节以 `motion-vocabulary.md` 为准）、声音（只看画面）。

## 一、一条片的骨架（几乎每条都是这个顺序）
```
0–1 秒   钩子：一个巨字 / 巨句，先于任何解释
1–5 秒   立题：常驻小标题（有的片）+ 第一句话 + 关键词
中段     内容：2–4 个「点」，每个点一个固定套路（见 §三）
          穿插：全屏素材 / 黑底卡 / 人缩成小窗，让画面不一直是正脸
结尾     行动：告诉他下一步点哪里（见 §四）
```
- **钩子**：66 条里 **45 条（68%）在前 1.5 秒就有字号 ≥ 全片中位数 1.8 倍的字**，中位数是 **2.4 倍**。（口径：工程文字轨，字号取剪映单位，比的是倍数。）接触表上看，钩子几乎都是 **2–4 个字的词**（垃圾 / 降息 / 广州 / 高考 / 亲子共读 / 失败 / 赚钱 / 一人之力），放在头顶或胸口，用黄 / 红 / 白三种色。
- **钩子字可以压在头后面**：「垃圾」「降息」「一人之力」「醒醒」都是头发 / 头顶盖住字的一小块（只盖一点点，字照样读得出）→ 用 `text-behind` 的 Headroom 做法，**并遵守「人只遮 8–20%」**（`text-behind-glass.md`）。
- 钩子一出现，下面立刻有一行小字幕在讲——**巨字是标题，字幕是正文，两者同时在**。

## 二、画面不是一直正脸：四种「呼吸」
| 手法 | 看到的样子 | 现有组件 |
|---|---|---|
| 人缩成**圆形头像**，字放旁边 / 下面 | 黑底，圆头像 + 一行字幕；「谁 ● 被打脸」「直接 ● 拉黑」是把大字拆成上下两块夹住圆头像 | `typed-quote`（圆窗）；**拆字夹头像 = 缺** |
| 人缩成**圆角小窗**，上方放证据 / 素材 | 法律、社评、创业最常见；窗角放红字小标题 | `pip-broll` / `split-broll` |
| **黑底引用卡** | 引号 + 逐字打出 + 关键词变色，下面圆头像 + 一行字幕 | `quote-card` / `typed-quote` |
| **整页素材**（海报、证件、纸张、实物） | 全屏停 1–3 秒，字幕在下 | `poster-hero` / `broll-bottom` |
- 目测**约 1/3 时间不是正脸全屏**（和 SKILL.md §2「两层节奏」一致；这是目测，没逐条计时）。
- 黑底卡和圆头像出现的位置：**章节转折、讲例子、读引用的时候**，不是随机插。

## 三、内容段的 6 个固定套路（挑一个套全片，别每段换）
1. **编号式**：角落一个小标 `No.1 / No.2 / No.3`（或「第一点 / 第二点」），整段不变；每个点下面是小字幕 + 关键词。（育儿、职场）
2. **清单累加**：「1. … 2. … 3. …」一条一条出现，**新的一条出现时，旧的变暗**；最后一句金句大字压过去。（知识付费）
3. **纸卡清单**：奶白纸底，左上圆头像 + 「三要素」标题，下面一条一条出，每条配一个卡通 / 实物图标。（创业、副业）
4. **关键词在字幕上方**：胸口字幕不变，**重点词单独放大一号、换黄 / 红，叠在字幕正上方**，字幕本身不动。（几乎所有片都有）
5. **关键词重复成墙**：同一个词（出轨）在人物四周多处浮现，大小不一、半透明，营造压迫感。（情感）
6. **数字 / 价格砸出来**：撕纸素材卡 + 黄色大数字（29888）+ 名字，数字用 `roll-in` 或 `slam`。（汽车、家居、财经）

## 四、结尾：一定有「下一步」
- 66 条里 **27 条（41%）结尾 4 秒的文字里有行动词**（找我聊聊 / 点击左下角 / 下期揭秘 / 联系我 / 点赞收藏）。（口径：工程文字轨的字；**蓝色胶囊、箭头多是贴纸，没算进去，实际比例更高**，总览图上结尾 0.8 秒几乎每条都有。）
- 结尾几种长相（总览图）：
  - **蓝色胶囊按钮**「找我聊聊 / 点我试试 / 点击领取」，放胸口下方（`Pill` 可做）；
  - **红 / 黄箭头指向左下角**（对应平台的头像 / 关注按钮）；
  - **「下期揭秘 / 下期揭晓」大字**，半透明压在人身后（`ghost-word` 可做）；
  - **「转给他看」+ 圆头像** 的黑底收尾卡；
  - 一句金句黑底收尾（引用卡）。
- 位置：全在安全区内（箭头指左下角是例外，**但仍要落在 y≤1250**）。

## 五、常驻小标题（约四分之一的片有）
- 例：`/成交高端客户/` 白 + `简单到离谱` 黄（两行），**整片都在顶部**（目测约 y 150–300 / 1920，**上半部分在我们的安全区 y≥250 之外**，所以照搬会被平台界面盖——学的时候整块下移到 y≥250）。
- 作用：晚点划到的人也知道在讲什么；也给钩子字留出位置。

## 六、强调的三个「小动作」（几乎每条都有，成本最低）
1. **推近 + 暗角**：说到重点那一刻推近，四周压一圈暗角，0.2–0.5 秒回来。
2. **一个词换色、放大一号**，其他字不动。
3. **贴纸**：红圈、箭头、「拒绝」印章、问号 `?`、REC 取景框——放在字旁边 1 个，不要多。

## 七、本库还缺的（诚实）
| 缺的模式 | 在哪些片出现 | 备注 |
|---|---|---|
| 拆字夹头像（谁 ● 被打脸） | 社评、贷款 | 圆头像在上下两块大字之间 |
| 人物**描白边剪影**（贴纸风）+ 背景虚化 | 全屋定制 | 要抠像，可用 `lift` + 白色描边，没做 |
| 撕纸素材卡 | 汽车 | 边缘锯齿的纸 + 素材，没做 |
| REC / 取景框叠层 | 汽车 | 纯画面，没做 |
| ~~清单累加（旧条变暗）~~ | 知识付费 | ✅ 已做：`stack-list`（`skeleton.tsx`） |
| 纸卡清单（奶白底 + 图标） | 创业 | 要自备图标 |
| ~~常驻小标题~~ | 疗愈、女性成长 | ✅ 已做：`top-title`（头顶没空间时要先下移画面） |
| ~~结尾蓝色胶囊 + 箭头~~ | 大部分 | ✅ 已做：`end-cta`（预览里的动态手感没验证） |
| 暗角推近 | 疗愈 | 没封装 |

三个 ✅ 在 library 的「骨架」分类里，代码 `remotion/craft/skeleton.tsx`；静帧检查过安全区，**动态没有逐帧看**。

## 八、怎么用这份文档
1. 先决定：**钩子字是什么**（2–4 个字，给 3 个候选让用户选）。
2. 选**一个内容套路**（§三）套全片。
3. 排 2–3 次「呼吸」（§二），放在转折 / 例子 / 引用处。
4. 结尾 **一定** 加行动（§四）：口播里本来就有行动话术（点左下角 / 找我聊聊）就用原话；用户给了账号 / 联系方式就用；都没有就问；**不能问就不放胶囊，别编账号**。
5. 以上都用现有组件拼，缺的（§七）先用最近的替代，并告诉用户「这一块没有现成组件」。
