# 字怎么搭配（Typography pairing）

回答三个问题：**字和字怎么配**（字体 / 颜色 / 大小 / 行数 / 位置）、**版式有哪几种家族**、**怎么把它们用对**。
这是「文字版式」的规则；动态看 `motion-vocabulary.md`。

|---|---|---|

| 「1-3 文字排版」 | 56 个演示，每个取**出现完成后**（演示开始后 2.5 秒）的一帧 | 同一句话的多种排法；**入场动态没看**（动态见 `motion-vocabulary.md`） |
| 「1-1 文字排版原则」 | 11 个演示 | 四个排版原则 |
| 这三个教学工程的文字轨（明文备份 `template.json.bak`，**完整解析**：每段文字的全部样式区间、投影、行距、位置） | 按「同一时刻出现」分组 | 字体 / 颜色 / 大小比 / 行数 / 位置 / **投影 / 行距**的统计 |

- 位置：剪映的 y 按 **y_px = 960 × (1 − y)** 换算成画面高度（1080×1920）。**已用 1-1 第一个演示核对**：工程里 y = −0.422 ↔ 第一行字中心约 y 1365 px，y = −0.544 ↔ 第二行约 1483 px，和截图里的位置吻合。

- 帧号按图鉴视频的顺序（1-2 #N）；可能和你工程里的版式编号差 ±1，**以画面为准**。

## 一、四个排版原则（1-1）
同一句话「35岁的我们 / 已经被这个时代抛弃了」被排了很多遍，每一遍只改一个原则：
| 原则 | 示范（看到的） | 怎么用 |
|---|---|---|
| **对齐** | 同样两行字，居中 / 靠左 / 靠右各排一遍 | **一支片只选一种对齐**；想破例（斜向错落）要是有意的 |
| **对比** | 「35岁」放得巨大，「的我们」缩得很小；或第一行黄、第二行白 | 靠**大小、颜色、粗细**拉开；不要「中等 vs 中等偏大」。主角词和配角至少 ~2× |
| **亲密** | 标题和它的说明紧贴，两组之间留一整行空白；用「1」「2」白底方块给每组编号 | 相关的行靠近，不相关的拉开；编号 / 小标把组分开 |
| **重复** | NO.1 / NO.2 / NO.3 三张**一模一样**的黄色卡片 | 并列的内容用**同一个样式**，位置规律一致 |

## 二、搭配的数字（来自工程文件的统计：颜色 / 字体 / 大小比 用 81 个版式的完整解析；行数用第一遍的 88 个）
### 颜色
| 角色 | 出现的颜色 | 次数 |
|---|---|---|
| 底色（白） | `#ffffff` | 162 |
| 重点 / 利益（黄） | 柔黄 `#fff589`（63）、金黄 `#ffbf17`（40） | 103 |
| 痛点 / 转折（红） | 深红 `#b71c1c`（19）、亮红 `#ff1837` / `#fe5252`（6） | 25 |
| 暗底上的强调 | 粉 `#ff619d` | 9 |
| 黑字 | `#000000`（观察到的都在白色小块里） | 22 |
**一个版式里的颜色种数**（完整解析，81 个版式）：1 种 26% · **2 种 54%** · 3 种 12% · 4 种以上 7% → **80% 只用 1–2 种**。（第一遍只数每段文字的第一个样式，得到 75%；完整解析后是 80%。）
→ 规则：**白色打底 + 一种强调色**；痛点用红、利益用黄；第三种颜色只给小块（标签 / 白底红字）。

### 字体
| 字体 | 次数 | 用在 |
|---|---|---|
| 思源粗宋（衬线粗体） | 137（41%） | 主角词、标题、数字 |
| 知新体 | 80 | 配角、说明 |
| 抖音美好体（无衬线） | 61 | 配角、列表、字幕 |
| 特黑体 | 18 | 列表小块（超粗黑体） |
| 思源宋体 Bold | 17 | 引用 |
| 得意黑 | 11 | 现代 / 硬朗的大字 |
**一个版式里的字体种数**（完整解析，81 个版式）：1 种 56%（45）· **2 种 41%（33）** · 3 种 4%（3）→ **96% ≤2 种**。混用时最常见的是**衬线 + 无衬线**（第一遍统计：混用的 31 个里 18 个；最常见思源粗宋 + 抖音美好体）。
→ 规则：**≤2 种字体**；主角衬线粗体、配角无衬线。本库主题：display = 思源粗宋、body = 抖音美好体、hand = 得意黑。

### 大小比（同一版式里最大字 : 最小字，81 个）
完整解析（81 个版式，算上同一段文字里的多个样式区间）：中位数 **1.5×**，四分位 1.2–2.58×；**≥4× 只有 8 个（10%）**，只给「主角词」（第一遍统计最高 ~12×）。
**同一段文字内部的大小对比很小**：只有 32 / 332 段文字有多个样式区间，其中位大小比是 1.0×（多数只换颜色或字体、不换大小），最大 1.7×。
→ 规则：**配角 : 主角 ≈ 1 : 2**；同一级别的行用 ~1.2× 做层次；**≥4× 的巨字全片只留 1–2 个**。

### 行数（88 个版式）
1 行 13% · 2 行 28% · 3 行 23% · 4 行 11% · 5 行以上 25%（多是「列表」演示）。→ 口播里**≤3 行**。

### 投影、描边、行距（完整解析新增）
- **描边：这三个教学工程里没有描边。** 文字样式里没有 `strokes`；`border_width = 0.08` 是每段都带的默认值，没有启用。（别和「白粗体 + 黑描边 13%」混——那是另一批模板包的拆解结论。）
- **投影：统一的一种硬投影。** 385 个样式区间里 316 个带投影，几乎同一个配方：**黑色、透明度 0.9（194 个）/ 0.8（96 个）/ 0.5 左右（21 个）、距离 5、角度 −45°、扩散 0.025（≈ 硬边，不是柔光）**。→ 字不靠描边，靠一道**偏下偏右的硬投影**压住背景。CSS 近似：`text-shadow: 4px 4px 2px rgba(0,0,0,0.9)`（剪映的「距离 5」不是 px，这是近似换算）。本库默认用的是柔投影（`0 4px 16px`），**没有改成硬投影**——要还原这个质感，用 `SHADOW_PACK`（见 `kit.tsx`）。
- **行距**（`line_spacing`）：单行 0.02（159 段）· 多行引文 0.17–0.22（110 段）· 疏的并列 0.67（23 段）。→ 单行紧、成段的引文松一些、并列项更松。
- **效果 / 关键帧**：这几个工程里没有关键帧；「效果」只是亮度 / 对比度这类调色参数；人像卡片用的是「矩形」遮罩。**动画的运动本身不在 JSON 里**（只有动画名和时长，运动在剪映的效果资源里）——所以动态必须靠放慢看画面，见 `motion-vocabulary.md`。

### 位置
原包文字的 y 中位数 ≈ −0.34（剪映坐标，0 = 画面中心，−1 = 最底），即约 **67% 画面高度（≈ y 1290）**；10 分位在 −0.55（≈ y 1490）。**一半以上的字在画面下三分之一。**（位置换算已核对，见上。）
⚠ **和安全区冲突**（下沿 y 1250，下面 35% 会被文案和按钮盖住）。本 skill 取交集：**所有字压进 y ≤ 1250**，把原包「下三分之一」那一带整体上移（`Zone`，见 `layouts.md`）。

### 同一句引言的 12 种排法（1-3 #24–35，「天才是 1% 的天分加上 99% 的努力」）
白边抠像人像 + 引言在上 · 引言压在人像上 · 虚化背景 + 引言 + 右对齐出处（「——爱迪生」）· **引言人物的白边贴纸** + 竖排姓名 · 圆窗 + 引言（第二行黄）· 取景框 + 暗角 · 手机框 · 大引号 + 圆窗 + 第二行放在圆窗旁 · 纯黑底居中 · 人像在下 + 引言（黄）在上 · 圆窗 + 多色行 · **巨大红色斜体「100%」垫在头后 + 胸口小字**。
→ 同一句话有 12 种解法，**选哪种看这一句在片里的功能**（引语 → 出处；数据 → 巨字）。

## 四、可以直接套的搭配公式
1. **底**：白色；**重点**：黄（利益 / 要点）或红（痛点 / 转折）；一个版式 ≤2 种颜色。
2. **字体**：主角衬线粗体 + 配角无衬线，≤2 种。
3. **大小**：配角 : 主角 ≈ 1 : 2；巨字（≥4×）全片 1–2 个。
4. **行数**：≤3 行；多于 3 行拆成两个版式。
5. **位置**：全部压进安全区（x 60–1010、y 250–1250），脸大时只放胸口带 y≈880–1250。
6. **原则检查**：同一支片里对齐方式一致；并列内容样式一致（重复）；相关的行靠近、不相关的拉开（亲密）；主角词一眼就是主角（对比）。
