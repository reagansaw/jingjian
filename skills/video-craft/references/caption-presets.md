# 字幕样式预设（657 款竖屏）

来源：「剪映字幕预设」合集里的 4 个包（191 + 318 + 160 + 152 款，共约 800 个预设，去重后竖屏 657 款）（每个预设是一个组合片段，里面有 1–10 段文字，每段有位置、缩放、颜色、描边、阴影、字体、入场 / 出场 / 循环动画、关键帧）。`tools/jy_preset_extract.py` 把它们转成样式规格 `remotion/craft/caption-presets.json`（只含数字和样式：**不含**原文字——示例文字多是作者品牌字，已换成占位——不含预览图、不含字体文件）。id 一律是 `cap-001…`（原文件夹名里有创作者名字 / 昵称，没有带进来）。图鉴：`docs/caption-presets.html`。

用法（`edit.json` 的 beats）：
```json
{ "kind": "cap-preset", "props": { "preset": "cap-040", "texts": ["第一点", "第二点", "第三点"], "at": 1.2 } }
```
- `texts` 按段顺序替换文字；字数超出规格时自动缩字。`at`＝整个预设开始的秒数（预设内部各段有自己的开始时间）。
- `dy` 整体上下移（px），`k` 整体缩放，`tone` 统一改色（如 `"#FFD27A"`），`speed` 播放速度。
- **不遮脸**：`python3 tools/place_check.py edit.json face.json --fix` 会按每段的位置和字号算占用的纵向范围，压到头就给出 `dy`。
- 自动配音效：预设开始时一个 `pop`。要更细的配音，自己在 `sfx` 里放。

## 诚实的限制
- **动画是按名字归类的近似**：84 个入场动画名按「淡入 / 放大 / 滑动 / 露出·擦除 / 模糊 / 弹入 / 翻转 / 打字机 / 逐字」几类用通用曲线重画，没有逐款逐帧量过；方向对，曲线细节不保证和剪映一样。
- **字号换算是估计**：剪映字号 15 ≈ 75px（按预设封面图估的）。
- **字体不同**：原预设用的字体（宋体类 / 黑体类 / 手写类 / 窄体）没有随库带，渲染时按类别退到本库字体，字形会不同；字体授权自己核对。
- 贴图填充（2 处）用纯色近似；带贴纸 / 形状 / 特效 / 蒙版的预设（35 款）只画文字部分。
- 预览是静帧（示范文字「示范文字…」），没有视频预览。
- 来源是付费素材包：本库只取样式数字、用自己的代码重画；不分发对方的文件、预览图、字体。

## 分类
每款有一个 `cat`（名字里的主题词）：2句字幕、关键词、2行字幕、4个大字、金句、重点信息、三段字幕、2句覆盖、2个大字、3句并列、开场文案、疑问、1句字幕、框架概要、序号、数字展示、弹幕……图鉴里可按分类筛。「其他」是名字里没有描述词的（原名只是编号）。
