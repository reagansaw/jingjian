# 文字动画词典（Motion vocabulary）

回答：**字怎么动**——有哪些入场动画、各自怎么动、多快、什么时候用、配什么音效。静态排版看 `typography-pairing.md`。

## 来源与可信度（先读）
- **「2-1 文字动画和音效常用搭配」**：38 种入场动画，每种演示 1–2 秒。**每一种都放慢拆帧**（每种取 8 帧，覆盖「入场时长 + 0.15 秒」，约 0.55–0.85 秒），逐个看它怎么动。
- **统计**来自 70 个口播工程的文字轨（明文备份）：2684 个文字片段、1249 个入场动画。
⚠ 局限：
- 每种只有 8 帧，**能看出「怎么动」，看不出精确的速度曲线**；本库的实现用 easeOutCubic 近似，不是还原。
- 「放大 / 缩小」的倍数是从帧里估的（缩小 II 约 3–4 倍起步，~0.35 秒落到 1 倍），不是读出来的参数。
- 这里的实现是**原创代码**，只借用了「动法」和「时长」，没有原包的任何素材。

## 一、数字（统计）
| 指标 | 数值 |
|---|---|
| 入场动画时长 | 中位 **0.4 秒**（p10 0.3 / p90 0.5）；模糊 / 光效类 0.7 秒 |
| 文字片段停留时长 | 中位 1.22 秒（p25 0.88 / p75 1.72） |
| **没有任何动画的文字片段** | **52%**（1400 / 2684） |
| 只有入场动画 | 45%（1197） |
| 入场 + 出场 | 2%（50） |
| 循环动画（情绪字用） | 34 次：飘起 8、文字泛光 7、弹幕滚动 5、扩音器 4、喷涌 3、情绪加载 2 |
| 出场动画（54 次） | 炸开 II 11、渐隐 10、消散 7、炸开 5、滚出 4、向下弹出 4 |
**用得最多的 10 个入场**（占全部入场的 44%）：渐显 110 · 缩小 80 · 放大 57 · 滚入 50 · 打字光标 48 · 随机上升 43 · 雪光模糊 43 · 轻微放大 40 · 冰雪飘动 39 · 开幕 37。
→ 规则：**不是每个字都要动。** 一半的字什么都不加，动画留给重点；出场几乎不用（2%），要收尾就淡出或「炸开 / 消散」。

## 二、38 种入场动画（放慢拆帧）
分五类。「预设」列：✅ = 本库有（`MotionText` 的 `preset`）；⏳ = 没做（多数是粒子 / 3D，或是已有预设的镜像 / 变体）。
次数 = 在 70 个工程里出现的次数（只列了前 30 名里的）。

## 三、按「功能」选动画
| 这一句要… | 用 | 配音效 |
|---|---|---|
| 平铺直叙（知识 / 叙述） | `fade` · `slide-up` · `curtain` | 纸张 / 轻呼，或不加 |
| **重击**（转折、狠话、金句） | `slam` · `shrink` · `echo` | 嘭 / 咚 / 撞击 |
| 数字 / 要点出现 | `grow` · `grow-soft` · `roll-in` | 叮 / 点击 / 收银机 |
| 定义 / 关键词 | `typewriter` · `develop` | 打字声 / 无 |
| 情感 / 玄 / 柔和 | `glow-blur` | 水滴 / 响铃 / 魔法 |
| 换话题 / 转场 | `blur-left` · `roll-in` | 呼 / 嗖 |
| 轻松 / 俏皮 | `wave-bounce` · `leap` | 气泡 / 啵 / 弹簧 |
| 标题 / 金句聚焦 | `tracking-in` | 嗖（轻） |
**每句换一个入场动画**（上一条的前期分析：「女性情感」模板每句轮换随机上升 / 跃进 / 打字光标 / 折叠 / 缩小），不要整支片用同一个；但**重点之外的字不用动**。

## 四、用法
```tsx
<MotionText th={th} text="剪出网感" preset="glow-blur" at={1.2} until={3.4} y={1040} size={150} />
```
`MotionText` 内部走 `FitBox`（量宽 → 超出安全区就缩小 → 推回），所以动画不会把字带出安全区。逐字类（`rise-random` / `wave-bounce` / `typewriter` / `develop`）每字一个 span，**字数 ≤8 最好**（长句会拖）。

## 五、还没做（诚实）
粒子类（冰雪飘动 / 星光 / 流光扩散）、3D 类（圆柱体滚动）、光效转场、折叠 / 便利贴 / 向上重叠、各种镜像 / 变体、**出场动画**（炸开 / 消散 / 滚出）、**循环动画**里的飘起 / 弹幕滚动 / 喷涌（情绪字用的 情绪加载 / 波浪 / 文字泛光 / 扩音器 已经做成 `EmotionWord`，见下）。

## 六、情绪字（循环动画，已做 4 个）
原包的「情绪字」= 一个普通文字 + 一个**循环动画**，放在人头上方。放慢拆帧（12 帧，间隔 0.12 秒）：
| 情绪字 | 原包循环动画（周期） | 看到的动法 | 颜色 | 本库 |
|---|---|---|---|---|
| 哭泣 | 情绪加载（1.27 秒） | 字先是白色，**红色像液体从下往上灌满**（~0.7 秒）；字距拉开 | 深红 `#b71c1c` | ✅ `EmotionWord kind="cry"` |
| 惊讶 | 波浪（0.98 秒） | 两个字**一上一下错开摆动**，各带 ±8° 倾斜，循环 | 金黄 `#ffbf17` | ✅ `kind="surprise"` |
| 非常开心 | 文字泛光（0.98 秒） | 淡黄字，背后**放射状光芒**随节拍明暗脉动 | 淡黄 + 金光 | ✅ `kind="joy"` |
| 救命 | 扩音器（3.0 秒） | 两个字**向外倾斜**，先淡入再轻轻摆动，向外扩出回声 | 金黄 | ✅ `kind="shout"`（摆动是近似） |
⚠ 原包把情绪字放在**人头上方**（y≈220–355）；本库的画面里头上没有安全空间，改放胸口带。⚠ 「真香」光晕翅膀、「嘤嘤嘤」眼泪是剪映内置的**人脸特效**（难过 / 真香 / 大头），不是文字，**没有做**（需要人脸跟踪）。⚠ 「扩音器」只有 3 秒周期的一小段可看，摆动幅度和回声是按画面近似的，不是还原。
用法：`<EmotionWord th={th} text="非常开心" kind="joy" at={1.2} until={3.4} />`。2–3 个字时字距自动拉开横跨宽度；更长的词保持正常字距。
⚠ 实现上踩过一个坑：渐变填色的字（`background-clip: text`）一旦子元素各自 `transform`，字就不渲染了——渐变必须放在每个字自己身上。
