# 抖音精剪（Douyin 精剪）配方

「精剪」= 在口播上做**密集的画面层变化**：素材（B-roll）、小人像窗（PIP）、分屏、海报大字、标签牌，配密集音效。
本文把「抖音精剪」整理成可执行的规则。

## 来源与可信度（请先读）
| 来源 | 是什么 | 做过什么 |
|---|---|---|
| 3 条参考片（剪辑 kiki 的**粗剪 vs 精剪**教程：左粗剪、右精剪、底部是剪映时间轴；**本仓库不附带**） | 8 月逐帧拆解出配方 | 本次维护者**重新看了一眼**其中一条的抽帧：左右对比、全屏素材 + 小人像窗、整屏海报、红字关键词，和配方一致 |
| 一套商业剪映口播模板包（99 个工程，**本仓库不附带**；每个工程里有明文的 `template.json.bak`） | 拆出字幕样式、动画名、音效名和落点 | 来自之前的拆解结论；本次没有重做 |
| 维护者某条广告成片的「抖音色规」 | 红 = 痛点、青 = 利益 | 来自当时的成片 |

⚠ **「精剪区每分钟 21–47 个切点」是 8 月的实测数字，这次没有重新量。** 参考片下半是静态剪映时间轴，全局镜头检测会被稀释——要量就**先裁到精剪区（右上）再检测**（阈值 0.12）。

## 第一定律：每 1.5–3 秒一个视觉变化，音频连续
音频不断、只换画面层。⚠ 这和主 SKILL 里「每 5–10 秒换一次**画面**」不冲突，是**两层**：
| 层 | 节奏 | 例子 |
|---|---|---|
| **视觉变化**（任何一种） | 每 1.5–3 秒 | 一个字块弹出、强调拍推近、素材进场、小窗换位、标签牌出现 |
| **换场**（整屏构图换掉） | 每 5–10 秒 | 卡片 / 黑底圆窗 / 手机 / 分屏 / 全屏素材 |
（这个「两层」是整理时把两条规则对齐的写法，**不是参考片原话**。）

**素材（B-roll）本身不附带**：组件里是占位画面，真用时把实拍 / stock / AI 图作为 `broll` 传进去。

## 文字 3 层
1. **底部常驻字幕**（照常）。
2. **海报大 hero 字**：只在关键名词出现，金（利益）或红（痛点），**会跨镜头慢慢长大**，出现时整帧压暗 40%（`poster-hero`）。
3. **黄色标签牌**：给素材命名，例如「3 号海洋塑料清理装置」（`LabelTag`，≤12 字）。

## 字幕样式（模板包共同地基）
- 白粗体 + **黑描边（字号的 13%）**，无底块。
- 关键词换色：黄（利益）/ 红（痛点）。
- 原配方把字幕挂在画面 **60–72% 高度**（y≈1150–1380）。⚠ **这和安全区冲突**（下沿 1250）。本 skill 取交集：**字幕 y ≤ 1230**，即只用 60–64% 那一段，其余让位。
- hero 字出现的那一瞬，字幕让开（别和大字叠在同一个 y——「字幕拦腰切过大字」是踩过的坑）。

## 每句一个入场动画（「女性情感」模板）
- 每句换一个入场动画轮换：随机上升 / 跃进 / 打字光标 / 折叠 / 缩小。
- 重点词**行内**放大约 2.25×、换金黄/暗红（不是独立花字层）。
- **拍子语法**：重点词**独占一拍**、整行放大（比「长句里嵌大字」更像原版）；最长的 1–2 个大字拍可以配满屏半透明飘字。

## 特效与音效
- 特效（时间轴直接读到的）：变速 1.1×、运动模糊转场、撕纸转场、滤镜、思考气泡贴纸、黑场聚光灯。（本库**还没做**撕纸/运动模糊转场/聚光灯。）
- 音效**很密**：每次版式切换、素材进场、大字弹出都垫一个。→ 见 `sfx-pairing.md`；一个动画一个**不同**的音。

## B-roll 规律：讲到什么名词，切什么素材
- 挑点：每 8–12 秒一个点；钩子前 3 秒不盖；单点 1–6 秒；版式轮换；标签 ≤12 字。
- 素材来源三路：
  - **概念 / 物件（约 8 成）**：stock（Pexels / Pixabay）够用，**不分华人**。
  - **要人 / 在地 / 具体产品**：**自己的素材（一等公民）** 或 **AI 生成**（图 → 视频）。
  - 没实拍就用 AI 海报图（参考片里「引来天敌」的鹰/狼/蛇海报就是 AI 的）。
- AI 影片后半段常变形 → 只取干净的一截，不够长就放慢。

## 版权（做开源必须守）
- 剪映缓存里的音乐/音效、模板包里的音档，**授权只限剪映内使用**，不能再发布——「能下载」不等于「可公开」。字体同理。
- 做法：用**声学指纹当菜谱**（量时长/峰位：峰在头 = 撞击、中前 = 嗖、尾 = 上升音），再去**可商用来源**找同指纹的替代。
- ⚠ **「免费使用」≠「可随仓库再发布」**：Mixkit / Pixabay 这类站点的许可通常**不允许单独再分发音档**。要把音效放进开源仓库，请选 **CC0** 的来源，并**逐个核对许可**；否则只放下载脚本/链接，让使用者自己下载。（未逐站核对各站的许可条款，发布前请确认。）
