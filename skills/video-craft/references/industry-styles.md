# 行业搭配预设（Industry style presets）

回答：**不同行业的口播，字体、强调色、动画、音效、节奏通常怎么配？** 先选一个「家族」，整支片守同一套。

## 来源与可信度（先读）
- 来源：剪映口播模板包「70 款口播工程」里的 **66 个行业成片**（去掉重复的副本后 64 个），中位时长约 23 秒。读的是每个工程的明文备份 `template.json.bak`（字体、颜色、入场动画、音效名）。
- ⚠ **「家族」是整理时按「首要字体 + 强调色」自己归的类，不是原包的分类**；归类规则是启发式的，边界上的成片可能归得不准（例如同一行业可能出现在两个家族里，因为有多个成片）。
- ⚠ 这是「大家通常怎么配」的统计，**不是「哪种配法效果更好」的结论**，没有做过效果对比。
- 原包的字体多数不能随仓库发布，本库自带的字体只有思源宋体 Heavy、得意黑、抖音美好体（见下表「本库」列）。

## 二、怎么选
1. **一支片只用一个家族**（字体 + 强调色 + 动画风格不要混）。
2. 强调色分工在所有家族里一致：**黄 / 金 = 利益、要点，红 = 痛点、转折**。
3. 想要「利落可信」（A）：得意黑为主，动画以 `fade` / `grow` / `shrink` / `glow-blur` 为主，音效偏「呼」和撞击。
4. 想要「温和有质感」（B）：衬线体，动画以 `fade` / `grow-soft` / `curtain` / `develop` 为主，音效偏纸张和「呼」。
5. 想要「明快讲干货」（C）：抖音美好体做配角，动画以 `shrink` / `fade` / `curtain` / `blur-left` 为主，音效偏刷、纸张、打字声。
6. 节奏参考：A 约 65 字块/分 + 34 音效/分；B 约 69 + 44；C 约 78 + 54（都是 15–60 秒短片的中位数，别照搬到长片）。
