# 抠像 · 字在人后 · 玻璃字

回答：**怎么让大字放在人的后面（人挡住字一点），以及怎么做「半透明玻璃质感」的大字。** 两样可以单用，也可以合用（玻璃字放在人后，最有「高级感」）。

## 来源与可信度（先读）
- 配方来自作者之前一个系列广告项目里反复用过的做法（玻璃字：同一个字叠两层，一层半透明定颜色、一层强光混合透出背景；字在人后：背景 → 字 → 抠像 PNG 盖在最上面）。本库把它们重写成原创组件 `GlassWord` / `TextBehind`。
- **原包里有没有这种用法？有（数据）**：73 个工程里 **62 个**带抠像素材（`videos[].matting` 标记，共 259 段），2684 个文字片段里 **196 个（7.3%）**在时间上被「更高轨道」的抠像片段覆盖 ≥50%——轨道顺序 = 图层顺序，抠像副本在文字上面就是「字在人后」。例子：1-3 的「消失 / 落伍 / 没节奏 / 哭泣 / 惊讶 / 非常开心 / 救命」（情绪字大多是这种叠法）。⚠ 局限：只比较了**时间**重叠，没比较空间位置；`matting` 标记不一定都是人像（也可能是物体抠像）；这批工程**没有**命名的段落标签轨（轨道名全为空，`time_marks` 只有 id）。
- **验证过的**：
  - 占位人形 + 木板墙：玻璃字里**能看到背后木板条的明暗纹理透进来**（放大看过）；字被人形挡住。
  - **真人口播（一条真实素材）+ 逐帧抠像 304 帧**：腾出头顶空间后，金色玻璃字在头顶上方，头发只盖住字的下缘一点点（量过：平均 13.6%），字读得很清；手和身体在字前面，头发边缘干净（看了 3 个时刻的静帧）。第一版（字和头同高）被遮 49.9%，不合格，已作废。
  - `lift` 主体抠像工具：单帧一次出干净的 PNG（人、手、衣服都抠得干净，肩膀边上有一小块残留）；逐帧脚本 5 帧跑通。
- **没验证的**：动态（逐帧抠像会不会闪）、不同光线 / 背景下的抠像边缘、长时间窗口、非 macOS、「没有明确前景主体」的画面。

## 一、玻璃字（`GlassWord`）
一个主角词，金黄渐层，但**背后画面的明暗纹理透进字里**，像毛玻璃。
- **做法**：同一个字叠两层——底层普通半透明渐层（`baseAlpha` 0.28，定颜色 + 一点投影）+ 上层 `mix-blend-mode: hard-light`（`lightAlpha` 1，把背后纹理透进字里）。
- **三条硬规则（违反就看不出玻璃）**：
  1. 两层**不能被任何带 `transform` / `opacity` / `filter` 的外层包住**，否则强光混合只会混到「透明底」。所以 **`GlassWord` 不能放进 `Zone` / `FitBox`**（它们都用 transform）；组件自己用 `fitSize` 算字号、入场动画只动每一层自己的透明度 / `top` / 字号。
  2. 它要混合的「背后画面」必须和它在**同一个 stacking context** 里：把它放进你放视频的那个 `div` 里面，不要放到外面。
  3. 背后画面要有**明暗起伏**（木纹、砖墙、窗帘）。一整片平的深色墙几乎看不出玻璃感。
- 渐层预设：`gold` / `pearl` / `rose` / `aqua`（也可以直接传一个 CSS 渐层字符串）。
- 用法：`<GlassWord th={th} text="剪出网感" size={230} at={0.3} until={3.4} y={760} grad="gold" />`。字太宽会按安全区宽度自动缩小。

## 二、字在人后（`TextBehind`）
层次：**背景画面 → 字 → 抠像 PNG（人 = 不透明，其余透明）盖在最上面**。人把字挡住一点，画面有层次。
- 字和抠像都要放进**和视频同一个镜头容器**里（坐标用视频的 1080×1920）。这样它们跟着手持晃动 / 推近一起走，字才像「贴在墙上」，抠像也才对得齐。
- **fail-closed**：`TextBehind` 在没有抠像的那一帧**不画字**。宁可没字，也不要字盖在脸上。
- 🔴 **硬规则：字必须一眼看得清，人只能遮住字的「一点点」。** 目标：字块被人遮住的比例**平均 8–20%、最多 ≤30%**（这是维护者的要求 + 经验阈值，不是原包数据）。**读不清 = 失败。**
- **为什么容易做坏**：画面里头顶没有空间（头顶 ≈ y 230，安全区上沿 250），字只能放在头的高度，头必然挡掉中间一大块。实测：把字放在头的高度（y 330–720），**平均被遮 49.9%**，两个字的词（420px）几乎读不出来——这是第一版的错误。
- **正确做法 = 先给字腾出头顶空间**（`Headroom`）：把整个镜头容器（视频 + 字 + 抠像）往下移 `dy`（例：250px），顶部露出的那条用视频顶部的**镜像**补上；字放在头顶上方，让头只盖住字的下缘。实测：字块 y=150（容器坐标，约 200px 高）时平均被遮 13.6%、最多 16.9%（y=40 时 0%，看不出「在人后」；y=130 约 10%）。
  - 屏幕 y = 容器 y + `dy`；字的屏幕位置仍要在安全区内（y ≥ 250）。
  - ⚠ 镜像补顶只适合「视频顶部那 `dy` 像素里没有人」（只有墙 / 背景）的素材；有人的话会镜像出半个头。素材头顶本来就有空间的话不需要 `Headroom`。
- **用 `tools/check_text_visible.py` 量**，不要只靠眼睛：给它字块在视频坐标里的矩形，它报告被人遮住的平均 / 最大比例，不通过就挪字。
- 抠像逐帧很慢：**窗口控制在 ~3 秒内**（75 帧 ≈ 9MB，304 帧 ≈ 44MB）。
- 用法（腾出头顶空间 + 字在人后 + 玻璃字）：
```tsx
<Headroom src={staticFile('rec.mp4')} startFrom={START} dy={250}>
  <TextBehind matteSrc={(f) => (f < N ? staticFile(`matte/${START + f}.webp`) : null)}>
    <GlassWord th={th} text="剪出网感" size={230} at={0.2} until={4.6} y={150} />
  </TextBehind>
</Headroom>
```
- 检查遮挡：`python3 tools/check_text_visible.py <抠像目录> <起始帧> <结束帧> 126 150 954 350`（字块的矩形，视频坐标）。

## 三、抠像怎么出（仅 macOS）
| 要抠什么 | 工具 | 速度（这台机器） | 说明 |
|---|---|---|---|
| **人** | `tools/mk_matte.py`（`personmatte.swift`，Apple Vision 人像分割） | 75 帧约 1 分钟 | 只抠人，边缘经过「往里收 1px + 羽化」处理 |
| **任意主体**（人、猫、产品…） | `tools/mk_subject_matte.py`（`subjectlift.swift`，Vision 前景主体） | 5 帧 11 秒（机器正忙），约 2 秒/帧 | 按「前景主体」抠；这一帧没抠到主体就不出文件，合成里就不画字 |
产出都是 `<输出目录>/<帧号>.webp`（RGBA）。帧号 = 视频里的第几帧，要和 Remotion 的 `useCurrentFrame()` 对得上（底片就是这条视频）。
**其他平台**：本库没有验证过。理论上任何能出「逐帧 RGBA」的抠像工具（如 rembg、MediaPipe、SAM）都能接上同样的文件格式（RGBA webp、文件名 = 帧号），**但没有试过**，不能保证质量。

## 四、什么时候用 / 别用
- **用**：开场标题、品牌词、一条片里唯一的大字；人像背景有明暗起伏。
- **别用**：同一支片里多次（全片最多 1–2 次）；背景是一整片平的深色（玻璃感看不出）；抠像边缘不干净（头发、半透明物体）时字会出现杂边；快速运动、人像被遮挡严重的段落。
- 安全区仍然要守：字整个落在 x 60–1010、y 250–1250（字在人后时，被挡住的部分不算越界，但露出的部分要在框内）。
